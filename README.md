# GoLeRobotics 공통 PR·Issue 템플릿

`GoLeRobotics/.github` 공개 저장소에 게시하면, 자체 템플릿이 없는 조직 저장소에 적용됩니다.

- `.github/pull_request_template.md`: PR 설명
- `.github/ISSUE_TEMPLATE/bug_report.md`: 버그 보고
- `.github/ISSUE_TEMPLATE/feature_request.yml`: 기능 제안
- `.github/ISSUE_TEMPLATE/task.yml`: 작업

개별 저장소에 자체 템플릿이 있으면 해당 템플릿이 우선합니다.
